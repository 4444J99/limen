## Three completion milestones

**Launch-ready:** coherent evidence-backed client/recruiter positioning; a working public proof path;
a minimal tested capture journey; bounded audit terms and a deliverable audit process; owner-approved
publication. This is an intermediate milestone, not PSP completion. It can produce useful conversations
before all product-handoff and quarterly work finishes.

**Externally validated:** genuine target-reader results; an owner-approved demand experiment;
documented qualified conversations; delivery and rejection evidence; updated positioning decisions.
The existing target remains at least five qualified door-mails and either one paid audit or five
documented no outcomes supporting a recorded revision. No research or code run manufactures these facts.

**Full Omega:** every existing leaf and phase satisfies its ratified acceptance branch; public/private
boundaries, delivery, operator custody and return loops are proven; two distinct unchanged complete
observations pass the canonical Omega predicate. The root then closes under actual authority.
Launch-readiness and a no-go decision must never be reported as full Omega by changing the denominator.

## Model, effort and consumption policy

Every leaf has a profile and effort in the crosswalk. Resolve the actual model from current provider
capabilities, availability and budget at run time; use provider Auto where metadata is insufficient.
Honor any newer explicit human override, but do not carry the old August root-ultra default forward
as an implicit permanent requirement. Record the real model/effort selected; never impersonate a provider.

| Profile | Default effort | Run slice ceiling | Appropriate output |
|---|---|---:|---|
| inspection | low | 15 minutes | Bounded current-state read, one evidence comparison or mechanical reconciliation |
| implementation | medium | 30 minutes | One coherent source/test/document change or rendered artifact |
| synthesis | high | 45 minutes | Cross-source decision, acceptance-contract correction, economics or substantial design |
| review | high | 20 minutes | One independent bounded challenge of a consequential change |

Ceilings apply per microphase run, not promises to finish a whole package in that time.
Use a cheaper adequate live option first; increase effort only for a demonstrated reasoning gap.
Routine formatting, status checks and waiting never receive frontier effort.
The current session may do bounded direct-human work; autonomous children still require the broker,
finite capacity and the native identity. No autonomous fanout is launched by this plan.

Before each run record: output, exact scope/owner, available allocation, model/effort, time/token or
provider-usage ceiling, one retry allowance, next receipt and stop condition. Do not invent dollar
costs when the provider does not expose them. Never purchase credits, redeem a reset or enable paid
overages without explicit authorization.

After each run report only: delivered artifact link, accepted gap delta, actual usage/time when
available, remaining blocker and next owner. A second failed corrective pass demands a smaller
contract/design decision, not more recursive reviewers. An unavailable reviewer never restarts the work.
