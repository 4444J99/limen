# User journeys and workflow shape

## Owner workflows

1. Capture source references, notes, messages, files, and commitments into the correct partition.
2. Classify incoming inbox items and promote accepted artifacts into tasks, decisions, or commitments.
3. Review prioritized commitments, waiting states, risks, and review queues.
4. Run collaborator prep with timeline, commitments, and decision context.
5. Approve or reject proposed actions from automations.
6. Produce redacted exports and run restore drills in isolated test environments.

## Collaborator workflows

1. Open a scoped portal with only the partition grant set.
2. Review assigned commitments and meeting prep within their allowed action set.
3. Submit updates through request-only paths that are policy-checked against partition grants.
4. Preview the session as a restricted view, including explicit revocation simulation.

## Operational workflows

- Import synthetic fixtures.
- Run scoped integrity checks for redaction, policy, and receipts.
- Back up encrypted state and run recovery comparisons.
- Reap stale work artifacts after exact-head preservation is proven.
