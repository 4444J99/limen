# Run-and-Gun Substrate

> Relocated verbatim from `AGENTS.md` (2026-08-06) under the instruction-surface byte budget
> (`institutio/governance/gates.yaml` → `instruction_surfaces`, check S). The binding stub in
> `AGENTS.md` points here; this file is the full doctrine.

The laptop must be able to operate alone as a thin control plane. GitHub commits hold the complete
recoverable collection; external SSDs are full mirrors and processing substrate.

- Keep the laptop as hot cache: active worktrees, small receipts, local tools, and enough context to
  continue from the remote owner without needing a drive at a coffee shop.
- Publish the complete collection to GitHub first: encrypted original recovery bytes and native
  metadata, processed/redacted corpora, repo/org custody, photos/media and provenance. Verify
  recovery from fresh remote fetches without local object alternates.
- Mirror that same full collection to both Archive4T and T7Recovery in the final external-drive
  pass, then verify restoration from each. No authoritative content lives only on an SSD.
- At the desk, assume externals are plugged in and use them for hydration, archive, media processing,
  and bulk scans; when unplugged, continue from remote receipts and cached indexes.
- Do not move, delete, dedupe, or purge personal data without the relevant two-copy/restore gate and
  an owner receipt.
