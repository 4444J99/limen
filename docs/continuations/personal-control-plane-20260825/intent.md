# Intent

Limen is the personal supra-organization controller. Its stable GitHub repository identity is
`1255213941`; its intended canonical coordinate is `4444J99/limen`, and `organvm/limen` remains a
historical alias whose receipts are never rewritten. The organizations continue to own their
domain products, policies, environments, and deployments.

This capsule executes one repository transfer, not a mirror or relay. Anthony supplies the ideal
form and orchestration; his 2026-08-25 correction delegates the transfer, merge, activation,
deployment, installation, and restart effects to the authenticated system lane. If GitHub rejects
the preferred destination before any mutation, the only permitted fallback is
`4444J99/limen-control`. A fallback transfer leaves every governed workflow disabled until a
follow-up change makes that observed coordinate canonical by repository ID; it is not predeclared
as an alias.

The controller verifies exact public organization targets from a pinned controller workflow and
verifier SHA. Target execution is read-only, secretless, and bound to the target repository and
exact target SHA. Any future cross-organization write belongs in a separate trusted finalizer with
repository-scoped credentials; the current deterministic worker has no write finalizer.
