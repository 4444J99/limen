## Registry archive and Claude's take

The named private archive's current tree has four files. Its atom JSON is 73,828,750 bytes;
its last file commit is dated 2026-05-24, while the repository's latest push is dated 2026-08-30.
The README describes a private preservation snapshot and claims 24,599 atoms. That total was
not independently recounted here. The discovery note confirms that the repository is a snapshot,
not a separate active system or native transcript archive.

Its legacy backlog report estimates substantial repetition among open atoms and proposes
doctrine-based closures. Those are historical analytical claims. Repeated atom text can suggest
recurrence, but it does not establish complete prompt sequences, unchanged authority, or equivalent
results. A written rule does not by itself prove that a concrete deliverable has been produced.
No atom was changed or closed during this comparison.

The Claude study and plan correctly distinguish verbatim recurrence from semantic intent families.
The registry-confirmation section was also read from live main and remains an unfilled placeholder,
not a completed scan receipt.
PR 3067 is still open and draft at the same head used for the earlier contract comparison.
It discloses that most labels are lexical suggestions and whole-corpus semantic equivalence is
unproven. Its twelve proposed contracts remain useful hypotheses, not an independent validation
of V5.

The native cases add important qualifications: rhetorical questions can require a repair;
an affirmative can reject an access denial; a clean review can supply evidence without granting
action authority; and new requirements cannot be discarded when choosing a short control verb.
The study therefore preserves each operation's target, actual payload, authority, constraints and
completion evidence. A repeated operation is not a promise of an identical fixed output.
