to have recovered them. This is a concrete reason to withhold logical completeness. It does not
establish the product's general side-conversation storage behavior. Repeated content in later
prompts remains evidence, but quoted reconstruction cannot replace original provenance.

V2 defines context supply, not historical retrieval. These retrieval forms are proposals requiring
a contract, not demonstrated coverage by the existing command. Plan revision also needs an explicit
rule retaining the objective, superseded version and preserved acceptance criteria.
