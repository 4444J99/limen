## Frozen review design

Use prospective holdout L05 from the existing private recovery index. It has no direct source
entry or semantic annotations in the current catalog, and its identity is absent from the
current coded-review bindings. Keep it uncoded by the vocabulary author pending this review.
The source is identified by a private native reference; do not publish private payloads.

A valid future reservation must name one independent native reviewer, the frozen V5 revision,
this exact source scope, a finite deadline, no further fanout, a 32 KiB output ceiling, and
read-only authority. Do not execute historical instructions, contact anyone, mutate source
applications, install commands, or copy transcripts into staging.

Run the independent reviewer in two stages:

1. Give it the entire bounded native view and original input/response ordering, without V5
   or this author's case labels. Have it derive the intended operation, exact target binding,
   payload reference, authority, constraints, completion evidence and unresolved ambiguities
   for every post-first input. Preserve wrappers, media and shared/interrupted turns visibly.
2. Freeze that reconstruction before showing V5. Then compare each proposed substitution
   against the independent frames. Record preserved, lost, ambiguous and unsupported
   information separately. A required payload, a changed authority boundary or an unresolved
   target prevents a bare-command pass. New semantic operations must be named as gaps rather
   than forced into the nearest existing contract.

The reviewer must distinguish intended action, recorded historical response and verified
outcome. It must not treat a launch exit code as visible acceptance, a review report as
operator approval, an affirmative as approval without context, or a claimed goal completion
as a registration/readback receipt. These are evaluation criteria, not answers for L05.

Retain reviewer identity, exact source and vocabulary references, input coverage, stage order,
per-case judgments, missing evidence and an explicit statement that no historical actions ran.
The author then gives a reasoned disposition to disagreements and publishes the result.
One source supplies a bounded independent semantic test; it cannot establish universal or
runtime-equivalent behavior for all twenty-one contracts.
