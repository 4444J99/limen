# Vendor-owned native Insights generator

The native Claude Code Insights report template is embedded in the vendor executable.
It is outside the locally owned Limen and Domus source repositories.

Confirmed native defects from the two October 16 report snapshots:

- Source hours already match America/New_York timestamps, but the native HTML labels
  the baseline Pacific and shifts selected Eastern counts another three hours.
- The satisfaction chart omits unclear labels and does not identify its repeated
  model-rating denominator. Cumulative session duration is not active human effort.
- Generated recommendations can contradict current local authority: missing paths,
  false lease availability, unconditional gate replay, unsafe retirement shorthand,
  and unbounded or unadmitted scheduled work.

Local mitigation is source-owned evidence validation and explicit unreviewed-proposal
classification; historical originals remain untouched. Correcting local interpretation
does not fix the native vendor template.

Owner: Claude Code vendor; local tracking: Limen's insight disposition ledger and this
issue. Acceptance: a supported vendor release generates date-aware correctly labeled
hour bins, explicit analysis/rating denominators, and recommendations qualified against
current configuration/authority; reproduce against synthetic data before closure.
Next action: carry a content-free synthetic reproduction through the vendor's supported
bug-report path when that authenticated destination is authorized/available. Do not
patch the signed/native executable or disable automatic updates.
